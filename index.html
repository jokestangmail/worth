Put Proof on Your iPhone

1. Host Free on GitHub Pages

  1. Create a new public or private repository on github.com named proof.
  2. Upload this file renamed to index.html.
  3. Go to Settings → Pages, set Source to Deploy from a branch (main / /root), and save.
  4. Copy your live username.github.io/proof link.

2. Add to iPhone Home Screen

  1. Open your GitHub Pages link in Safari on your iPhone.
  2. Tap the Share icon (square with upward arrow) at the bottom of Safari.
  3. Scroll down and tap Add to Home Screen, then tap Add.
  4. Proof now opens full-screen like a native app and works offline.
